# 阶段路线

阶段目标用于排序与拆分工作，不承诺发布日期。任务状态、负责人、阻塞与验收证据以 [GitHub Issues](https://github.com/xiaodaozhi/xdstarter/issues) 和 [Milestones](https://github.com/xiaodaozhi/xdstarter/milestones) 为准。

| Milestone | 目标 | 退出条件 |
| --- | --- | --- |
| M0-Foundation | 仓库、规格、设计资产、协作入口与许可决策 | 文档和模板落地；自动检查通过；发布许可完成决定或明确阻塞 |
| M1-Prototype | Qt 工程、精确磁贴布局、Windows 系统集成原型 | 三档布局与输入导航可演示；材料/焦点/唤起可测；接管边界有真机结论 |
| M2-Alpha | 应用目录、搜索、编辑、分组、本地持久化与高保真界面落地 | 核心日常启动流程可用；重启恢复；失效目标与损坏配置可验证；v2 设计基准、深浅主题、多档有效缩放与真机交互完成视觉验收 |
| M3-Beta | 兼容、辅助功能、性能与安装发行 | 支持矩阵、依赖审查、安装卸载、恢复路径和回归测试通过 |

## 工作排序

先验证 Windows 窗口与接管的关键不确定性，再扩大完整功能。UI 原型和接管研究可独立进行，但不能在验证前承诺替代系统菜单的兼容范围。

M2-Alpha 收尾设置独立的[高保真界面落地与视觉验收门槛（Issue #29）](https://github.com/xiaodaozhi/xdstarter/issues/29)：先统一 [v2 修订 2.2](../design/README.md)，再落实整体版式、控件状态和细节；以实际 QML 抓帧及产品交互核对，设计导出不能替代运行时验收。此门槛完成后，M3-Beta 继续扩大兼容性、辅助功能、性能与发行验证；不会因本机有效缩放或局部交互通过而自动退出 M2 或宣布完整 Beta 兼容通过。

初始待办覆盖许可选择、Qt 工程、磁贴布局、系统接管、应用目录、搜索、布局编辑/持久化及 Beta 验证。后续新增需求和 Bug 直接建立 Issue，并关联上述里程碑；本页不维护平行任务清单。
