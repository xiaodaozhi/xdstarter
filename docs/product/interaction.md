# 交互设计

本文件区分当前 Qt Quick 菜单原型与后续完整目标。[Issue #14](https://github.com/xiaodaozhi/xdstarter/issues/14) 已将 [#13 的设计素材](https://github.com/xiaodaozhi/xdstarter/issues/13) 接入运行时；[#15](https://github.com/xiaodaozhi/xdstarter/issues/15) 接入无边框和外部焦点收起；[#16](https://github.com/xiaodaozhi/xdstarter/issues/16) 改为自绘外观与统一面板边距。本轮 [#22](https://github.com/xiaodaozhi/xdstarter/issues/22) 增加用户显式启用的单独 Win 键唤起。开始按钮接管、搜索和分组管理继续按对应 Issues 推进。实际验证范围见[测试策略](../technical/testing.md)。

## 浏览与启动

当前菜单没有系统标题栏，顶部保留应用标识、编辑、主题和“收起菜单”入口，左侧为快捷栏和所有应用，右侧为磁贴分组。窄窗口通过“所有应用／返回磁贴”切换正文，保留布局；搜索框属于后续搜索功能。

通过托盘或已启用的独按 Win 键显示时，先在隐藏阶段快速读取目标显示器、工作区与任务栏 DPI 并定位，再显示窗口，不等待开始按钮识别。可见面板距工作区左边缘、距底部任务栏顶端均为 8 DIP，屏幕容纳不下时以工作区夹限优先。外侧阴影不算作面板边距，透明外窗可跨出工作区。不将设计稿固定坐标用于实际桌面；任务栏左对齐、居中及各显示器组合均需实际验证。待显示期间再次切换或主动收起会取消此次唤起，旧查询结果不能重新打开菜单。

单击或 Enter 启动应用；启动失败保留窗口并显示原因，成功后收起，把焦点交给目标程序。托盘可再次显示；若托盘不可用，成功启动后最小化到任务栏以保持可恢复。异步定位完成不重新抢占用户已切走的焦点。

Esc 先关闭当前子菜单或取消拖拽，再退出编辑，最后收起主菜单。“收起菜单”按钮直接收起，退出程序需选择明确的退出入口。托盘可用时收起仅隐藏窗口；托盘不可用时最小化，保留任务栏恢复入口。系统关闭窗口的退出策略与主动收起分开处理。独按 Win 键仅在用户启用后切换菜单，系统开始按钮仍保持原生行为。

菜单确实获得焦点后，点击桌面、其他应用或切换到外部窗口，持续失去焦点时收起；若初次激活被系统拒绝，保留窗口供用户操作。内部尺寸、固定、电源与关于菜单在同一 Qt Quick 窗口内呈现，打开、选择和关闭它们不会被误认为切换应用。本窗口拥有的临时子窗口也属于内部焦点。真正切至外部时会连同子菜单一起收起，不因子菜单仍打开而永久停留。

拖拽且鼠标左键仍按下时，延后外部焦点检查，避免指针越出菜单便中断拖放；松开或取消后再检查。失焦收起会取消未提交的拖拽预览，保留已提交布局和编辑模式。处于编辑模式不阻止外部收起，重新唤起时恢复磁贴或可操作控件焦点，不恢复悬空的子菜单或拖拽状态。

## 左侧快捷栏

快捷栏宽 64 DIP，每项使用 48×48 DIP 命中区，普通线描图标为 24 DIP；顶部头像为 32 DIP 圆形。深浅主题共用几何，图标从独立 SVG 加载。头像为圆形占位图，不表示已读取当前用户照片；点击进入账户设置。

文档与下载打开系统对应目录；设置打开 Windows 设置，头像打开账户信息设置。请求交给后台服务，同一时刻处理一个动作；忙碌时禁用重复入口，失败在原窗口说明原因，成功后按应用启动的收起／恢复规则处理。未连接服务的 smoke 窗口只反馈不可用。

快捷入口有可见键盘焦点、完整辅助功能名称及鼠标/焦点提示；Tab 与 Enter 可操作。电源图标先打开带文字的“电源与退出”菜单，提供 Win 键唤起启用/暂停和“退出 XDStarter”。关机、重启和注销尚未启用，点击图标不会直接执行系统电源操作。

## 搜索

本节为后续目标。查询非空时正文切换到结果列表，清空时还原浏览位置与分组状态。匹配优先级为名称完整匹配、名称前缀、名称包含、拼音匹配；相同分数使用稳定名称排序，避免每次打开结果跳动。

查询为空展示正常菜单；无结果展示当前查询与清空入口。目录扫描过程中允许使用已有缓存，并显示后台更新状态。已卸载目标从结果中移除，已固定但失效的磁贴提示重新选择或取消固定。

## 编辑磁贴

右键应用可固定，右键磁贴可调整尺寸或取消固定。进入“编辑布局”后允许拖拽及跨现有分组移动；创建、重命名分组与修改应用显示名称仍待后续开发。拖拽期间显示与真实目标尺寸一致的占位框，松开后才提交布局。

调整大小保持左上锚点；有冲突时显示无效预览，由用户选择其他落点，不静默覆盖其他磁贴。取消操作还原拖拽前布局。缩小窗口使用滚动容纳现有布局。

小磁贴只显示居中图标，鼠标悬停和键盘聚焦显示名称，辅助功能名称始终可读。标准与宽磁贴显示图标和名称；长名称省略并提供完整提示。

## 系统控制与恢复

当前原生托盘文字菜单提供“显示/隐藏 XDStarter”、Win 键唤起启用/暂停/恢复和“退出 XDStarter”。菜单收起后可以从托盘恢复，退出则停止接管、保存布局并释放资源。操作托盘文字菜单期间延后焦点收起检查。托盘注册失败时保留窗口及最小化任务栏恢复方式，并停止 Win 键接管；Explorer 重启后的重新注册已有代码，实际恢复仍需验证。

每次启动默认关闭 Win 键唤起，不从布局恢复此开关。支持环境且托盘可用时，用户可从窗口电源菜单或托盘选择启用，界面显示实际启用、暂停或失败状态，等待启用结果时不接受重复请求。启用后单独按下并释放左右 Win 键切换 XDStarter；长按重复不连续切换，其他按键或鼠标参与时不算独按。Win+E/R/L/数字等组合按原始输入路径交给系统，其兼容性仍须按确切环境验收。

用户可随时暂停，失败或托盘不可用时也停止接管。托盘恢复、新进程启动或错误条件消失均不自动重新启用，需用户再次操作。系统开始按钮一直保持原生入口，暂停或退出后 Win 键回到系统路径；不采用先打开原生 Start 再关闭的闪烁方案。当前只支持本地 Windows 11 的显式原型启用，不把安全桌面、锁屏或 UAC 作为接管目标。

开始按钮左键接管、打开系统开始菜单的独立命令和开机启动管理继续按父 [Issue #6](https://github.com/xiaodaozhi/xdstarter/issues/6) 等后续任务推进。机制与失败边界见 [ADR-0008](../technical/adr/0008-win-key-capture.md)；只有[测试策略](../technical/testing.md)记录过的物理键盘、组合和恢复用例才算实际验证。

## 辅助功能与视觉

保持可见焦点，方向键根据网格邻近位置移动，Enter 启动，提供无鼠标的编辑与收起入口。菜单主题实色面板使用共享 12 DIP 圆角、1 DIP 单层边框和自绘柔和阴影；侧栏背景沿面板同一路径裁切，正文保留内边距。透明外窗每侧留 24 DIP 容纳阴影，不改变正文和磁贴尺寸；点击透明角或阴影区域可收起。Windows 原生圆角、边框和阴影被禁用，实际外观按当前版本验收。当前不启用 Mica/Acrylic 或背景模糊材料；高对比度、远程会话及关闭系统效果等组合仍需专门验证，动画不应影响应用启动与输入接收。
