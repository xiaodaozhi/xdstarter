# 交互设计

## 浏览与启动

顶部为搜索框，左侧为快捷栏和所有应用，右侧为磁贴分组。菜单从任务栏所在显示器的工作区内出现，避免超出屏幕；任务栏左对齐与居中都进入兼容测试。

打开后可以直接输入。单击或 Enter 启动应用；启动失败保留菜单并显示原因。成功启动后收起菜单，把焦点交给目标程序。点击面板外部关闭，菜单内的上下文菜单、拖拽与确认框不视为外部点击。

Esc 有明确层次：先取消当前拖拽或关闭子菜单，再清空搜索，最后关闭主菜单。系统组合键保持原行为。

## 搜索

查询非空时正文切换到结果列表，清空时还原浏览位置与分组状态。匹配优先级为名称完整匹配、名称前缀、名称包含、拼音匹配；相同分数使用稳定名称排序，避免每次打开结果跳动。

查询为空展示正常菜单；无结果展示当前查询与清空入口。目录扫描过程中允许使用已有缓存，并显示后台更新状态。已卸载目标从结果中移除，已固定但失效的磁贴提示重新选择或取消固定。

## 编辑磁贴

右键应用可固定，右键磁贴可调整尺寸或取消固定。进入“编辑布局”后允许拖拽、跨组移动、创建与重命名分组。拖拽期间显示与真实目标尺寸一致的占位框，松开后才提交布局。

调整大小保持左上锚点；有冲突时显示无效预览，由用户选择其他落点，不静默覆盖其他磁贴。取消操作还原拖拽前布局。缩小窗口使用滚动容纳现有布局。

小磁贴只显示居中图标，鼠标悬停和键盘聚焦显示名称，辅助功能名称始终可读。标准与宽磁贴显示图标和名称；长名称省略并提供完整提示。

## 系统控制与恢复

托盘提供打开菜单、设置、暂停/恢复接管、打开系统开始菜单和退出。电源操作使用带文字的系统操作菜单，避免单击图标直接关机。开机启动由用户选择，卸载或退出释放接管。

## 辅助功能与视觉

保持可见焦点，方向键根据网格邻近位置移动，Enter 启动，提供无鼠标的编辑入口。尊重高对比度、关闭透明和减少动画设置。动画不影响应用启动与输入接收。
