# 交互设计

本文件区分当前 Qt Quick 菜单原型与后续完整目标。[Issue #14](https://github.com/xiaodaozhi/xdstarter/issues/14) 已将 [#13 的设计素材](https://github.com/xiaodaozhi/xdstarter/issues/13) 接入运行时；[#15](https://github.com/xiaodaozhi/xdstarter/issues/15) 接入无边框和外部焦点收起；[#16](https://github.com/xiaodaozhi/xdstarter/issues/16) 改为自绘外观与统一面板边距；[#22](https://github.com/xiaodaozhi/xdstarter/issues/22) 接入用户显式启用的单独 Win 键唤起。[#8](https://github.com/xiaodaozhi/xdstarter/issues/8) 接入本地应用与固定目标搜索；[#9](https://github.com/xiaodaozhi/xdstarter/issues/9) 增加分组管理；[#29](https://github.com/xiaodaozhi/xdstarter/issues/29) 建立完整菜单视觉；[#41](https://github.com/xiaodaozhi/xdstarter/issues/41) 将其更新为 v2 修订 2.3 的默认可编辑交互。磁贴显示名称编辑及搜索别名联动由 [ADR-0011](../technical/adr/0011-tile-display-names.md) 定义，开始按钮点击与自适应任务栏见 [ADR-0014](../technical/adr/0014-start-click-and-adaptive-taskbar.md)。实际验证范围见[测试策略](../technical/testing.md)。

## 浏览与启动

正常首次运行在托盘后台驻留，不自动弹出菜单；托盘不可用时显示窗口以保留恢复入口。同一用户、同一 Windows 会话只运行一个实例，重复启动通过本机 IPC 唤起原实例，不创建第二份菜单或竞争布局写入。原实例尚未响应时有界等待后报错退出，不绕过单例锁。smoke 不访问真实单例、托盘或用户布局。

当前菜单没有系统标题栏，顶部以搜索框为主入口，右侧为“更多选项”和“收起菜单”。不再提供编辑模式开关，也不显示编辑说明／新建分组工具栏；“更多选项”保留新建分组、主题、保存、导入和关于。布局随时可拖动；未达到拖动阈值的单击仍启动应用。所有提示等待悬停 600 ms，离开取消；禁用菜单项不展示额外 hint。键盘 Tab／Shift+Tab 导航时显示焦点装饰，点击、触摸、滚轮、Esc 或应用停用时清除装饰，实际输入焦点仍保留。所有中文文本和磁贴名称统一使用系统 Microsoft YaHei UI／微软雅黑字体，不分发字体。

正文为快捷栏、240 DIP应用目录和动态磁贴分组。目录按#、A–Z和末尾地球图标分类；分类入口及应用图标32×32 DIP，分类选择覆盖列表视口且内容居中。移除刷新旁无交互的A–Z文字及逐项图钉；拖动或右键固定，默认最后一个分组。已固定应用右键可原子取消该目标的全部固定磁贴；只读及导入提交期间拒绝修改。应用菜单关闭后的延迟焦点恢复不抢走已移到其他可用控件的焦点；来源被移除且没有其他交互焦点时回到“更多”。

开始菜单目录保留文件夹层级，同层同规范相对路径的公共／用户目录合并，两侧子项完整保留；快捷方式按自身路径标识，不按最终exe去重以免丢参数。名称优先使用Shell正常本地化显示名，失败回退物理名。点击文件夹后在列表区域展开，矢量返回箭头居中；标题独立于内容，空态不覆盖标题。tooltip只跟随真实悬停或Tab导航焦点，打开菜单、拖动、离开、切换目录及窗口隐藏都会取消，鼠标右键焦点不使提示常驻。

每次唤起都在隐藏阶段读取目标显示器、工作区、实际任务栏边缘和只读对齐偏好，完成原有混合 DPI 稳定检查后显示。底部左对齐时左／底各 8 DIP，水平居中任务栏时菜单水平居中；顶部任务栏改为左／顶 8 DIP，左右任务栏使用邻接工作区的上角，右侧镜像，垂直居中时菜单在工作区垂直居中。定位失败保留有恢复入口的窗口，不将旧矩形用于点击命中。边缘缩放随停靠方向改变：底部用顶部／右侧，顶部和左侧用底部／右侧，右侧用底部／左侧；水平居中时另允许左侧，垂直居中时另允许顶部。通过 Qt 系统 resize 调整，非拖动边保持固定，透明阴影不应使可见边缘在松手时跳动；收起重开后按当前方向和对齐重新定位，保持 48/8 DIP 磁贴几何。其他 Windows 版本、自动隐藏和各任务栏组合的实际支持以验证记录为准。

单击或Enter启动应用，失败保留窗口并显示必要原因，成功后收起并把焦点交给目标。正常启动、固定／取消固定、刷新和保存成功不显示浮动提示。菜单始终不显示系统任务栏窗口按钮；托盘可恢复。若托盘不可用，保留可见的重试／退出界面并暂停接管，不能隐藏或最小化到不可发现的状态。

Esc在输入法预编辑期间交给输入法，其他时候先关闭子菜单或取消拖拽，再退出文件夹／分类或清空搜索，最后收起。托盘可用时各收起入口共用退出动画及真实隐藏；托盘失效时外部失焦保留恢复界面，主动关闭最后恢复界面正常退出。开始按钮服务只消费当前可信点的完整左键，托盘与电源菜单可独立暂停／启用。

菜单确实获得焦点后，点击桌面、其他应用或切换到外部窗口，持续失去焦点时收起；若初次激活被系统拒绝，保留窗口供用户操作。内部尺寸、固定、分组、电源、更多与关于菜单，以及组名编辑弹层在同一 Qt Quick 窗口内呈现，打开、选择和关闭它们不会被误认为切换应用。本窗口拥有的临时子窗口也属于内部焦点。真正切至外部时会连同子菜单一起收起，不因子菜单仍打开而永久停留。

确认新建分组后，焦点返回该分组的操作按钮；旧菜单关闭后的延迟回调不能覆盖已经转移到其他可见控件的焦点。

拖拽且鼠标左键仍按下时，延后外部焦点检查，避免指针越出菜单便中断拖放；松开或取消后再检查。失焦收起会取消未提交的拖拽预览及组名草稿，保留已提交布局和编辑模式。处于编辑模式不阻止外部收起，重新唤起时聚焦搜索框并保留当前查询，不恢复悬空的子菜单、组名草稿或拖拽状态。

## 左侧快捷栏

快捷栏宽64 DIP，按钮48×48 DIP、普通矢量图标24 DIP、圆形头像32 DIP；底部四项间距为0，命中区域不重叠。深浅主题共用几何，头像为占位图，点击进入账户设置。

文档与下载打开系统对应目录；设置打开 Windows 设置，头像打开账户信息设置。请求交给后台服务，同一时刻处理一个动作；忙碌时禁用重复入口，失败在原窗口说明原因，成功后按应用启动的收起／恢复规则处理。未连接服务的 smoke 窗口只反馈不可用。

快捷入口有可见键盘焦点、完整辅助功能名称及鼠标/焦点提示；Tab 与 Enter 可操作。电源图标先打开带文字的“电源与退出”菜单，提供 Win 键唤起启用/暂停和“退出 XDStarter”。关机、重启和注销尚未启用，点击图标不会直接执行系统电源操作。

## 搜索

搜索框始终位于正文顶部，Ctrl+F 聚焦并选择已有查询，先前排队的菜单或分组焦点恢复不得抢走搜索焦点；通过托盘或已启用的 Win 独按重新唤起菜单时也聚焦搜索框。支持原名称、英文和中文的拼音全拼／首字母；英文与中文混合名称保留英文片段，例如 `Windows 终端` 可用 `windowszhongduan` 或 `windows zd` 查找。查询完全在本地执行，不搜索未固定的任意文件，不提供命令行或网络搜索。

排序依次为名称完整匹配、名称前缀、名称包含、拼音全拼、拼音首字母；同档按规范化显示名称及稳定目标 id 排列。应用目录和已固定目标按 id 去重，目录名称优先展示，磁贴名称作为可搜索别名；没有目录记录的固定目标继续可搜索。最多显示前 100 项，同时提示匹配总数。每行保留图标、完整名称提示和可用状态，不因图标迟到重建整个结果列表。

查询和名称按 Unicode NFKC 与不区分大小写规范化；拼音不区分声调，`ü`、`u:` 与 `v` 等价。有效查询最多 128 个 UTF-16 代码单元，避免从中截断代理对；超长名称及候选数遵循 [ADR-0010](../technical/adr/0010-local-application-search.md) 的索引上限。拼音采用逐字多读音匹配，没有词级消歧，可能接受罕见读音及不符合当前词义的组合，不提供错别字纠正或完整汉语读音保证。

输入法预编辑文本不提交查询，预编辑期间 Enter 不启动结果，Esc 不清空查询或收起菜单；提交文字后才开始搜索。搜索框向下键进入结果，结果上下键移动，首项向上返回搜索框，Enter 启动当前项；忙碌或不可用结果不启动。结果启动只提交受控 id，平台继续复核可用性，失败保留菜单与原因。

查询非空时正文切换到结果列表，进入时保留应用列表的滚动和选中项、磁贴区的横纵滚动及当前浏览视图。清空按钮或 Esc 清空后还原这些位置；编辑模式与布局保持。重新唤起保留当前进程中的查询，重启从空查询开始，不把搜索文字写入布局文件或日志。

查询变更立即使旧结果失效并显示搜索状态；后台只处理一个索引／查询任务，完成后转向最新查询和最新目录，旧版本结果不能覆盖新状态。目录扫描时使用已有快照并显示更新提示；刷新失败保留旧目录。相同查询的结果元数据更新按目标 id 保留选中项及焦点，过期恢复回调不抢占已转向其他控件的焦点。刷新后已卸载且未固定的目标离开结果；已固定但失效的目标保留不可用原因，用户仍可返回磁贴视图取消固定。

## 编辑磁贴

右键应用可固定，右键磁贴可调整尺寸或取消固定。默认允许拖拽及跨组移动；拖拽期间显示与真实目标尺寸一致的占位框，松开后才提交布局。右键或 Shift+F10 的磁贴菜单提供“修改显示名称”和“恢复原名称”，浏览模式也可操作；仅覆盖当前磁贴，不改变系统应用目录名称、原目标名称或启动目标。

Shift+F10 仅作用于当前聚焦的磁贴、应用目录项或分组管理按钮；在输入框、输入法预编辑、拖拽、其他内部弹层或隐藏状态下不抢占按键。菜单键仍可打开相同入口。只读配置允许查看磁贴菜单，由各修改动作保持禁用。

磁贴调整大小优先保持左上锚点，占用冲突由确定性规划器挤开其他磁贴。网格列数随实际可用宽度变化，保持48 DIP小格和8 DIP间隙，不拉伸磁贴；窗口缩窄时先保留可容纳原位，再稳定安置越界项，64行容量不足则整次拒绝。拖拽和导入提交期间延后宽度提交，过期预览取消；500 ms去抖后才更新列数并按当前格式保存。窗口宽度吸附与工作区最大边界共用纯几何，非拖动边固定。详见ADR-0015。

显示名称弹层说明“仅修改此磁贴”和最多 128 个字符，表情可能占两个字符；首尾空白会去除，空名称、超限、控制字符或换行明确报错，不静默截短。保存或非输入法预编辑 Enter 才提交，取消／Esc／外部收起丢弃草稿；预编辑期间 Enter、Esc 先交给输入法。恢复原名移除覆盖。小磁贴提示、完整辅助名称及标准／宽磁贴标签同步；目标身份、颜色、尺寸、坐标和启动描述保持。搜索继续按目标去重，原名和各磁贴覆盖都可查找，结果名称优先显示目录名称。

小磁贴只显示居中图标，鼠标悬停和键盘聚焦显示名称，辅助功能名称始终可读。标准与宽磁贴显示图标和名称；长名称省略并提供完整提示。

## 分组管理

“更多选项”提供“新建分组”，各组标题右侧的“⋯”打开“管理分组”菜单；菜单项为“重命名”“上移分组”“下移分组”“删除空分组”。Tab 聚焦该入口后可按 Enter 或 Shift+F10 打开，方向键选择菜单项，Enter 执行。组顺序同时用于磁贴浏览和固定目标分组选择。新建分组追加到末尾并使用新的稳定 groupId；重命名及排序不改变 groupId，也不改变任何磁贴的 tileId、targetId、坐标或尺寸。

组名提交前去除首尾空白，结果不能为空、最多 128 个 UTF-16 代码单元，原始输入不能包含控制字符或换行。允许重名，以稳定 groupId 区分操作对象；名称不作为标识。最多 32 个分组且至少保留一个。非空分组不能直接删除，需先将磁贴跨组移走或明确取消固定；删除空分组不会取消固定或移除应用目标。边界操作与只读配置禁用修改入口，controller 也复核这些条件，不仅依赖按钮状态。

组名弹层内的文字只有点击“保存”或非输入法预编辑期间按 Enter 才提交；输入法预编辑期间 Enter、Esc 交给输入法。Esc、“取消”或外部失焦收起丢弃尚未提交的组名文本，不写入布局。组名编辑与内部菜单使用同一窗口焦点规则，打开它们不会收起整个菜单；提交失败保留当前布局并显示原因。已提交操作沿用布局的合并保存及退出 flush，重启恢复名称和数组顺序。

分组名称与分组排序不参与应用搜索；相同应用仍按 targetId 去重，目录与固定目标的搜索名称未变时不重建索引。分组与磁贴显示名称编辑共用既有保存通道，显示覆盖的严格 schema 3 兼容策略见 [ADR-0011](../technical/adr/0011-tile-display-names.md)；布局导入与上一份布局恢复由 [#10](https://github.com/xiaodaozhi/xdstarter/issues/10) 跟踪。

## 导入与恢复布局

“更多 → 导入布局…”选择本地布局文件，标题不带 JSON；不再展示“恢复上一份布局…”菜单项。后台原子备份和恢复能力继续保留。Windows 文件选择优先使用操作系统原生打开文件对话框，以菜单窗口为模态父窗口；取消或 Esc 回到菜单，不自行绘制系统选择器或强制其使用软件深浅主题。预览保留软件内的确认弹层，以纯文本单行显示文件名、最多两行显示目录，通过提示及辅助说明保留完整来源；同版显示一个格式版本，旧版显示迁移箭头，另列分组／磁贴／应用目标计数、主题，以及替换全部布局的说明。无效、超大或较新格式明确报错，不自动改读其他文件，不启动导入目标。

点击“确认替换”才提交，确认对象是预览时已校验的内容。期间显示进度并暂停布局和主题编辑；已提交的新修改使旧预览失效。存在尚未保存的编辑时先正常保存它们，导入保存成功后再替换界面；导入失败时仍保留当前布局，已正常保存的此前编辑不回滚。正常退出等待当前保存事务，重启恢复已经成功保存的布局。只读、样例模式或未配置持久化时禁用导入和备份恢复。

## 视觉反馈与布局密度

v2 修订 2.3 的几何、字体和深浅颜色由共享视觉 tokens 定义，磁贴实体几何继续来自 tile-grid。浏览时每组仅占已使用的行高，空组显示紧凑提示；进入编辑后恢复服务定义的完整放置区域，支持拖拽到空行。两种模式均不修改已保存的格坐标、磁贴尺寸或组顺序。

正常浏览不常驻品牌大标题、平台诊断、成功状态或保存按钮。成功反馈最多显示 4.5 秒，隐藏窗口时停止计时；再次显示不恢复过期成功提示。目录扫描忙碌、应用失败、保存失败、配置只读和备份恢复等需要注意的状态持续可见，直到有新的状态替代。错误类型来自 C++ 结构化结果，不解析中文消息判断严重程度。提示采用主题独立的错误文字颜色，完整名称与错误原因按纯文本显示。

磁贴底色从共享调色板按稳定目标身份选择；重命名、跨组移动、尺寸和主题切换不改变该身份或配色。颜色不表示应用品牌，图标仍由系统提取。小磁贴居中显示 28 DIP 图标，标准／宽磁贴显示 36 DIP 图标及底部名称；标签和提示均按纯文本显示。

## 系统控制与恢复

当前原生托盘文字菜单提供“显示/隐藏 XDStarter”、Win 键唤起启用/暂停/恢复和“退出 XDStarter”。菜单收起后可以从托盘恢复，退出则停止接管、保存布局并释放资源。操作托盘文字菜单期间延后焦点收起检查。托盘注册失败时保留窗口及最小化任务栏恢复方式，并停止 Win 键接管；Explorer 重启后的重新注册已有代码，实际恢复仍需验证。

每次启动默认关闭 Win 键唤起，不从布局恢复此开关。支持环境且托盘可用时，用户可从窗口电源菜单或托盘选择启用，界面显示实际启用、暂停或失败状态，等待启用结果时不接受重复请求。启用后单独按下并释放左右 Win 键切换 XDStarter；长按重复不连续切换，其他按键或鼠标参与时不算独按。Win+E/R/L/数字等组合按原始输入路径交给系统，其兼容性仍须按确切环境验收。

用户可随时暂停，失败或托盘不可用时也停止接管。托盘恢复、新进程启动或错误条件消失均不自动重新启用，需用户再次操作。开始按钮服务与 Win 键分别管理；暂停或退出对应服务后回到系统路径；不采用先打开原生 Start 再关闭的闪烁方案。当前只支持本地 Windows 11 的显式原型启用，不把安全桌面、锁屏或 UAC 作为接管目标。

开始按钮点击的实现与限制见 ADR-0014；打开系统开始菜单的独立命令和开机启动管理继续按父 [Issue #6](https://github.com/xiaodaozhi/xdstarter/issues/6) 等后续任务推进。机制与失败边界见 [ADR-0008](../technical/adr/0008-win-key-capture.md)；只有[测试策略](../technical/testing.md)记录过的物理键盘、组合和恢复用例才算实际验证。

## 辅助功能与视觉

“更多 → 外观主题”提供跟随系统、浅色、深色。默认沿用深色；旧配置中显式选择的深浅色保持不变。跟随系统时，系统外观变化更新界面而不改写用户偏好，无法识别系统外观时回退深色。手动改选深色或浅色后不再跟随。实际 Windows 主题切换、高对比度及屏幕阅读器需单独验收。

键盘导航焦点使用适应深浅表面的颜色；磁贴焦点在原有尺寸内绘制外圈和内圈，分别与面板及磁贴底色区分。鼠标操作后按既有规则取消键盘焦点提示。

Windows 高对比度启用时使用用户的系统窗口、文字和选区颜色；普通控件用边框区分焦点与交互状态。磁贴及应用目录的多色图标暂以名称首字替代，快捷栏显示简短文字，完整名称仍供提示和辅助工具使用。原有主题选择保留，系统高对比度关闭后恢复；不会因切换系统设置而改写布局。实际系统主题、屏幕阅读器和各项交互的验收仍见 [#34](https://github.com/xiaodaozhi/xdstarter/issues/34)。

遵循 Windows 的客户端动画偏好；关闭动画时以静态状态呈现窗口、菜单和磁贴，按压仍有颜色反馈。读取失败时采用减少动画。切换时已在进行的菜单过渡允许完成，之后不再播放；偏好不写入布局。实际系统切换与完整辅助功能体验仍需独立验收。

保持可见焦点，方向键根据网格邻近位置移动，Enter 启动，提供无鼠标的编辑与收起入口。菜单主题实色面板使用共享 12 DIP 圆角、1 DIP 单层边框和自绘柔和阴影；侧栏背景沿面板同一路径裁切，正文保留内边距。透明外窗每侧留 24 DIP 容纳阴影，不改变正文和磁贴尺寸；点击透明角或阴影区域可收起。Windows 原生圆角、边框和阴影被禁用，实际外观按当前版本验收。当前不启用 Mica/Acrylic 或背景模糊材料；高对比度、远程会话及关闭系统效果等组合仍需专门验证，动画不应影响应用启动与输入接收。

## 动画与反馈

磁贴左键按下使用按点3D透视：[Issue #58](https://github.com/xiaodaozhi/xdstarter/issues/58) 修正为围绕对侧边或对侧角倾斜，按下侧向后退，对侧接近原位。姿态由按点方向的一次合成轴旋转得到，最终倾角不超过10度，整个平面最大后退不超过16 DIP，视距180 DIP，不能分别叠加两轴上限。中心按下收缩至0.985并下沉2 DIP，两者随按点远离中心而衰减。各角深度属于同一平面，方形磁贴沿对角按压时两枚相邻角可以等深。按下90 ms，松开180 ms恢复，恢复途中再次按下从当前姿态连续过渡，参数来自共享`motion.tilePress`。

48×48、104×104和216×104 DIP磁贴在正常显示尺寸下，按住常用边缘或角落区域时，应能直接看出按下侧后退、边长缩短以及图标和文字同步透视；可见位移和边长差也纳入自动检查。运行时验收应对照同尺寸的按下前、按住和恢复画面，并检查实际按下与恢复过程。背景、图标和标题共用投影，按钮命中矩形与拖动偏移不随倾斜改变；拖动开始、取消或禁用时复原，隐藏时立即停止并复原。右键和键盘激活保持原有路径，不模拟鼠标按点。此效果参考Windows磁贴按压反馈，不宣称复刻系统私有动画参数；实际验证范围见[测试策略](../technical/testing.md)。

主菜单180 ms淡入并上移10 DIP，120 ms淡出；host在可见前将进度设为0，每轮只启动一次，重复唤回不会先全显再重播，也不关闭真正自有前台对话框。右键／下拉菜单120 ms淡入并0.98→1缩放，90 ms退出；hover直接进入中性底色，不先经过强高亮。磁贴保持有界位置／尺寸和固定／取消动画，文件夹100 ms退场、170 ms进入。必要错误反馈可关闭，按错误来源隔离关闭状态，成功操作不使旧错误重现，新的同文失败仍可显示。2.4已验收[浅色菜单](../design/mockups/v2/proposals/issue-48/menus-light.png)与[深色浮层](../design/mockups/v2/proposals/issue-48/overlays-dark.png)是视觉合约，实际抓帧另记。
