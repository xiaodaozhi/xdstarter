# 产品愿景

状态：产品方向已确认；功能尚未实现。

## 目标用户与价值

为偏好 Windows 10 磁贴开始菜单的 Windows 11 用户提供可整理、可记忆、可快速启动的入口。用户能够通过固定位置与分组找到常用应用，也可以直接输入名称搜索。

成功体验是：按 Win 键打开菜单，一次点击或输入即可启动目标；整理后的磁贴在重启后保持位置；系统更新或程序异常时仍能回到系统开始菜单。

## 首版边界

- 产品支持目标：Windows 11 x64。具体构建与多屏组合通过真机测试逐步列入支持矩阵。
- 主体：应用目录、静态快捷磁贴、三档尺寸、分组、拖拽编辑、搜索与本地保存。
- 系统融合：Win 键与开始按钮接管为目标能力，先验证兼容性；保留暂停接管和退出入口。
- 视觉：Windows 10 的结构与 Windows 11 的现代质感，深浅主题、清晰文字与键盘可达。
- 首版不纳入动态信息磁贴、新闻、天气服务、云同步、文件全文索引或跨平台产品发行。

Qt 的跨平台能力用于复用通用逻辑与界面开发。Windows 的系统接管与兼容承诺仍以 Windows 真机结果为依据。

## 产品原则

1. 固定布局保持稳定，窗口尺寸变化时优先滚动，不擅自打乱已保存的位置。
2. 磁贴尺寸和间隙由统一网格推导，普通磁贴保持正方形。
3. 日常启动快速；应用扫描、图标获取与保存不阻塞输入。
4. 默认本地运行、普通用户权限，尊重系统主题与辅助功能设置。
5. 系统接管可暂停、可退出、可恢复，异常时优先保留系统原有行为。
