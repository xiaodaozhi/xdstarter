## 重点规则

- 小磁贴的“半宽”指网格占位：`48 + 8 + 48 = 104`。四枚小磁贴连同中缝占一枚标准磁贴的位置。
- 宽磁贴宽度为 `104 + 8 + 104 = 216`，不能直接采用 208 DIP。
- 搜索不触发网络请求，首版不搜索未固定的任意本地文件。
- 性能数字是待验证目标，需记录设备、构建、样本量、P95、内存与 GPU 环境。
- 接管验证不通过的系统组合继续使用原生开始菜单，不能标记为已支持。

## 变更方式

新增或修改需求先在 Issue 中明确场景、收益、范围与验收。通过后在关联 PR 更新本文件及受影响设计。重大方向或兼容性取舍通过 ADR 留痕。
