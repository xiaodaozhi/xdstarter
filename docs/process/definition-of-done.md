# 完成定义

## 所有交付

- Issue 的验收标准满足，实际完成范围与描述一致。
- 适用检查通过，PR 记录实际运行的命令、环境和结果。
- 产品行为、设计、技术说明和用户文档同步。
- 未完成或未知的内容明确记录，不能将设计、目标或模拟结果声明为实现完成。

## 功能与 Bug

功能覆盖主流程与重要异常；Bug 有根因说明及原复现步骤的回归结果。布局修改核对实际截图的小/标准正方形、宽磁贴和间隙；不能仅检查常量。

涉及 Windows 接管、材料、焦点或安装的修改必须有 Windows 真机证据。Mac/通用单测仅覆盖相应通用能力。配置变化覆盖兼容与恢复，平台资源在退出/失败路径释放。

## 文档与设计

链接有效、状态准确、当前版本明确。PNG/SVG 与源数据一致，实际目视检查文字、图标和排列。新图进入当前版本目录，旧图归档；重新生成后刷新需要的校验数据。

## 发布

Milestone 中阻塞项关闭，支持矩阵与已知问题完整，安装/更新/卸载和原生菜单恢复通过。依赖、许可证、签名与校验值符合发布清单，Release notes 链接 Issues。
