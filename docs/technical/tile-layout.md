# 磁贴布局技术设计

对应需求：PRD-003、PRD-005、PRD-009、PRD-011；进度与验收见 [#5](https://github.com/xiaodaozhi/xdstarter/issues/5)、[#9](https://github.com/xiaodaozhi/xdstarter/issues/9)。

## 唯一几何来源

[tile-grid.json](../design/tokens/tile-grid.json) 定义 `cell=48`、`gap=8` DIP。设计稿中的 app/group 仅为示例数据，不直接充当用户运行时配置。

以小磁贴为一格：小 1×1、标准 2×2、宽 4×2。位置与尺寸统一计算：

```text
pitch = cell + gap = 56
x = column × pitch
y = row × pitch
width  = columnSpan × cell + (columnSpan − 1) × gap
height = rowSpan × cell + (rowSpan − 1) × gap
```

配置只保存整数格坐标及 `small`、`standard`、`wide` 尺寸枚举，不保存像素宽高。每组独立坐标系，宽度固定十格、552 DIP；当前服务限制最多 64 行。主题与缩放不改变逻辑几何。

## 原型布局与呈现

普通首次启动提供空的“常用应用”分组；smoke 与测试夹具可使用工作、日常、娱乐三组、15 枚样例。[Issue #29](https://github.com/xiaodaozhi/xdstarter/issues/29) 区分浏览与编辑的呈现高度，避免浏览时每组常驻大块拖放留白：

- 浏览网格使用磁贴实际占用高度 `max(tile.y + tile.height)`；空组使用 56 DIP 提示区域。样例各组初始占用 104 DIP。
- 编辑网格使用 service 提供的完整拖放空间：`max(216, occupiedHeight + 2 × pitch)` DIP，宽度始终为 552 DIP。样例初始编辑高度为 216 DIP；向下移动后，继续在最底部磁贴下保留两行空位。
- 组标题为 32 DIP，至网格间距 8 DIP，组间距 24 DIP，来自[视觉 tokens](../design/tokens/visual.json)。模式切换可改变后续组的屏幕位置及滚动范围，不改动组内磁贴的整数坐标、尺寸或共享几何，也不将呈现高度写入配置。

`TileGroup` 用实际 `grid.height` 计算组外框，拖放命中同一 `gridItem` 坐标系。容器高度不是磁贴高度，编辑留白不能被截图检查误判成被拉长的磁贴。

`MenuController.groups → TileGroup → TileButton` 呈现 C++ 提供的逻辑矩形。小磁贴只显示居中图标；标准与宽磁贴使用固定内部名称区，长名称省略，完整文本由 ToolTip 与 `Accessible.name` 保留。文本、焦点描边与内部布局均不撑开外框。样例不会枚举或启动已安装应用。

各组按布局快照的数组顺序纵向排列于双向滚动区域。最小窗口 480×480 DIP，不重排或缩放磁贴；Tab/Shift+Tab 或方向键聚焦时把目标滚入视口。方向键邻接由 C++ 按方向投影与距离计算，组内没有上下目标时寻找相邻非空组，左右不跨组；边界无目标时保持焦点。

## 拖拽与尺寸变更

当前实现以下路径，已运行的自动与实际窗口证据按版本在[测试策略](testing.md)区分记录：

1. 点击“编辑布局”启用左键拖拽；跨过系统拖拽阈值后显示与原磁贴同尺寸的落点框，原磁贴降低透明度。
2. 将指针转换到目标组的逻辑坐标，保留按下时的偏移，再按 56 DIP 步距四舍五入到候选整数格。
3. QML 调用 controller 的 `previewPlacement`，由 `PrototypeService::checkPlacement` 排除自身后检查分组、十列/64 行边界和占用。合法与非法落点使用不同颜色，并显示原因。
4. 松开时仅提交一次；`moveTile` 再次校验，跨组移动在一个内存操作内完成。无效落点或 Esc 取消保持原布局，不保存指针中间帧。
5. 视口边缘可触发拖拽滚动；滚动不修改格坐标。拖拽结束恢复磁贴焦点，模型刷新后以稳定 tileId 定位。

右键或 Shift+F10 打开尺寸菜单，可在小、标准、宽三档间切换。`resizeTile` 保持左上锚点并使用同一落点校验；冲突或越界明确拒绝，不自动挤开、覆盖或重新排布其他磁贴。尺寸菜单也可在浏览模式使用；只读配置禁用编辑入口。

纯键盘操作：Tab/方向键选择磁贴，进入编辑模式后 Ctrl+方向键每次移动一格；普通方向键仍负责导航。Esc 在输入法预编辑期间交给输入法；其他时候先关闭子菜单或取消拖拽，再清空搜索、退出编辑，最后收起菜单。取消只针对尚未提交的操作，不表示提供已提交操作的撤销历史。

编辑提交后产生布局快照并合并保存，主题也持久化。固定/取消固定及真实应用目标已接入相同通道，图标与启动不改变磁贴格坐标。保存失败保留当前内存布局、显示失败原因，可重试。磁盘原子写入、备份与版本保护见[数据与持久化](data-persistence.md)。

## 分组事务

[Issue #9](https://github.com/xiaodaozhi/xdstarter/issues/9) 本轮增加新建、重命名、相邻上移/下移和删除空分组。操作沿用 `QML → MenuController → PrototypeService`；controller 要求编辑模式且配置可写，service 再校验名称、组数与稳定 id，成功后一次提交并更新分组模型。拒绝的操作不改变内存布局、不触发保存，原有磁贴拖拽和碰撞规则不变。

- 分组总数为 1–32。新建追加空组并生成独立 groupId；名称 trim 后非空、最多 128 个 UTF-16 代码单元，创建与重命名拒绝原始输入中的控制字符或换行，允许重复名称。
- 重命名只修改组名；排序只改变 groups 数组中的位置，不重新打包磁贴，不修改 tileId、targetId、尺寸或组内整数格坐标。方向键跨组导航与固定分组菜单随新顺序更新。
- 只删除空组，且不能删除最后一组。非空组需先跨组移动或明确取消固定以搬空；删除操作不隐式取消固定、丢弃或挤移磁贴。
- QML 使用稳定 groupId 操作和恢复焦点，不把名称或数组下标当作身份。组名编辑是内部 `Popup.Item` 暂态；取消、Esc 或外部收起丢弃未提交文本，输入法预编辑不提交操作。

组名与顺序直接写入现有 schemaVersion 2 的 `groups[].name` 和数组顺序，无需升级格式。已提交操作走同一 500 ms 合并保存、原子写入和退出 flush；只读恢复策略照旧。分组不参与应用搜索，单纯重命名或排序不重建搜索索引。磁贴显示名称编辑尚未接入，不能将本轮分组事务等同于 [#9](https://github.com/xiaodaozhi/xdstarter/issues/9) 全部验收完成。

## DPI 与像素边界

布局内部使用 Qt 逻辑坐标与高 DPI 支持；Win32 物理定位只在平台层转换，避免重复乘缩放。需要像素吸附时由左右/上下端点求差，不累加分别四舍五入后的宽度。拖拽预览、命中区域、描边和最终布局共享同一几何。

真实窗口抓帧测试扫描磁贴的物理边界、间隙和组合外框。`scripts/verify-windows-ui.ps1 -NativeScales` 在 Windows QPA 下先探测基础 DPR，再校准五档 Qt 有效缩放。此检查不修改 Windows 系统缩放，不代替混合 DPI 跨屏验证；命令和实际证据见[测试策略](testing.md)。

## 验收

- 四枚小磁贴含中缝与标准磁贴外框一致；两枚标准磁贴含间隙与宽磁贴一致。
- 100/125/150/175/200% 实际截图最多接受 1 物理像素光栅误差，不接受累计错位或长宽比改变。
- 编辑覆盖组内/跨组移动、非法落点、Esc 取消、三档尺寸与冲突拒绝、键盘编辑和保存后重启恢复。
- 分组覆盖新建/重命名/排序/空组删除、重名与稳定 id、1/32 组边界、非法名称、非空删除拒绝、只读保护、输入法/取消/失焦及重启恢复；操作前后磁贴目标与共享几何保持一致。
- 长名称、可访问名称、主题、缩窗滚动、方向导航与像素几何继续回归；跨屏 DPI 和屏幕阅读器单独真机验收。
- 运行时截图是像素验收对象，不能仅凭常量或示意图判定通过。
