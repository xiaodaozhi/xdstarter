# 磁贴布局技术设计

对应需求：PRD-003、PRD-005、PRD-009、PRD-011。

## 唯一几何来源

[tile-grid.json](../design/tokens/tile-grid.json) 定义 `cell=48`、`gap=8` DIP。设计稿中的 app/group 仅为示例数据，不直接充当用户运行时配置。

以一枚小磁贴为一格：小 1×1、标准 2×2、宽 4×2。位置与尺寸统一计算：

```text
pitch = cell + gap = 56
x = column × pitch
y = row × pitch
width  = columnSpan × cell + (columnSpan − 1) × gap
height = rowSpan × cell + (rowSpan − 1) × gap
```

用户配置保存整数格坐标及尺寸枚举，不保存像素宽高。每组独立坐标系。相同主题与缩放下，磁贴的几何计算完全一致。

## QML 实现约束

采用模型驱动的自定义磁贴布局组件。模型提供逻辑矩形，QML 负责渲染；布局组件自行管理占位，不依赖 Flow 的自动换行。若使用 GridLayout，必须固定单格尺寸及跨度，禁止布局扩张把正方形拉成长方形。

图标与名称位于磁贴内部，不参与外部测量。小磁贴只显示图标；长名称不能撑开磁贴。统一使用内部描边或裁剪，避免外部描边改变可见间隙。

## 拖拽与尺寸变更

- 把指针映射到分组逻辑坐标，再映射为候选格坐标；预览与最终提交调用同一计算函数。
- 占用表按 tileId 记录格子，编辑时排除自身，检查负坐标、越界和碰撞。
- 尺寸变更保持左上锚点；放不下时拒绝该落点并提示，不覆盖其他磁贴。
- 拖拽期间只更新预览；松开合法落点后提交一次，Esc 或无效落点还原原布局。
- 分组与屏幕滚动不修改保存坐标。跨组移动在一次事务内更新原组与目标组。

## DPI 与像素边界

内部使用 Qt 的逻辑坐标和高 DPI 支持。窗口物理定位使用 Win32 时，在适配层统一转换，避免再次乘缩放系数。

需要像素吸附时，从共享逻辑边界换算左右/上下端点，再求差；不要分别累加四舍五入后的宽度。拖拽预览、命中区域、描边和最终布局使用相同边界。

## 验收

- 四枚小磁贴含中缝与标准磁贴外框一致；两枚标准磁贴含中缝与宽磁贴一致。
- 100/125/150/175/200% 缩放下核对实际截图，接受光栅化边缘最多 1 物理像素误差，不接受累计错位或长宽比改变。
- 覆盖长名称、组间移动、非法落点、重启恢复及跨屏 DPI 变化。
- 运行时截图是像素验收对象，不能仅凭 JSON 参数或示意图判定通过。
