# ADR-0011：磁贴显示名称覆盖与 schema 3

- 日期：2026-10-21
- 状态：采用；构建与实际窗口验收按[测试策略](../testing.md)记录
- 关联：[Issue #9](https://github.com/xiaodaozhi/xdstarter/issues/9)、PRD-004、PRD-006、PRD-007
- 延续：[ADR-0003](0003-layout-snapshot.md)、[ADR-0004](0004-application-catalog.md)、[ADR-0010](0010-local-application-search.md)

## 背景

固定磁贴原先直接显示已保存目标的 `name`。需要允许用户仅修改某枚磁贴的标签，同时保留目录名称、稳定目标和启动描述。schema 2 对磁贴字段严格白名单校验：直接在同版本增加字段会被旧程序当作损坏输入，不能依赖旧程序忽略未知字段。

同一目标的重复固定操作仍返回既有磁贴；合法恢复文件可能已有多个 tileId 引用同一 targetId，因此显示覆盖不能写到共享目标对象而影响其他磁贴。

## 决定

1. 当前写入 **schemaVersion 3**。在 `groups[].tiles[]` 增加可选 `displayName` 字符串，缺省表示使用 `targets[].name`。不保存空字符串作为恢复原名；恢复操作移除此字段。原始目标数组、targetId、tileId、groupId、快捷方式路径、AUMID、图标 key、坐标和尺寸均不因改名改变。
2. 覆盖仅作用于当前 tileId；同目标的其他磁贴可以保留不同名称。目录列表始终显示系统目录名称，改名不重命名系统快捷方式、应用、分组或磁盘文件。重新固定已存在的目标不重置覆盖；取消固定后重新固定是新磁贴，使用原目标名称。
3. 新名称先拒绝原始控制字符、换行、Unicode 行／段分隔符和无效 UTF-16，再 trim；结果须为 1–128 个 UTF-16 代码单元。表情通常占两个单元，不截断代理对；重复名称允许。schema 3 中该可选字段须为已 trim 的规范字符串，拒绝空白、未知字段、错误类型和超限；schema 1/2 不接受新字段。
4. 保持严格的 schema 1、2、3 读取规则。读取旧文件仅将内存快照升级为 3，不自动写盘或改变源文件。首次编辑／显式保存仍经过完整校验、原子保存与退出 flush，上一有效主配置的原始字节保留在 `.bak`。旧程序将 schema 3 识别为未来版本而只读，不允许通过伪装 schema 2 绕开保护。
5. 搜索按 targetId 去重，目录名称优先作为结果名称，原 target 名称和所有有效磁贴显示覆盖作为别名。目录缺失时原 target 名称仍作为结果名称；改名、恢复原名及取消固定更新名称快照并使旧查询结果失效，旧覆盖不作为永久历史别名保留。原索引每目标 16 个普通名称、8192 条输入及256字符限制保持；显示覆盖使用独立输入，整个索引共享最多512条预算，与布局最大磁贴总数一致，不将每个目标的普通预算扩大到512。图标、启动及名称覆盖不改变目标身份。
6. 磁贴右键／Shift+F10 菜单提供“修改显示名称”和“恢复原名称”，与尺寸菜单一样可在浏览模式使用；只读配置禁用，controller 与 service 同样复核。内部 `Popup.Item` 弹层显示限制与作用范围，保存／非预编辑 Enter 才提交；取消、Esc 或外部收起丢弃草稿。输入法预编辑期间 Enter／Esc 不提交或关闭；错误文字、完整提示与辅助功能名称均按 PlainText 显示。

## 验证与影响

服务检查覆盖 trim、边界／emoji、控制字符与无效 UTF-16、未知 tileId、共享目标独立覆盖、恢复原名、只读及失败不变性。保存检查覆盖 schema 1/2 原字节不变、首次 3 写入的旧版备份、严格版本字段、重启覆盖与较新配置保护。

GUI 检查覆盖菜单键盘入口、可见 128 限制、预编辑、取消／外部收起、标签及辅助名称、颜色／几何不变、重建恢复和目录／原名／所有覆盖的搜索别名。实际产品独立进程、真实托盘与真实应用启动按最终二进制另行验收；离屏回归不等同这些 Windows 行为已通过。

本决定只扩展显示元数据，不增加启动目标类型、任意命令、网络查询或新运行依赖。导入界面由 [Issue #10](https://github.com/xiaodaozhi/xdstarter/issues/10) 后续消费相同严格 schema 3 校验，不因本次改名能力视为完成。
