# ADR-0018：系统主题偏好与布局兼容

日期：2026-10-29。状态：已接受（阶段实现）。关联 [#34](https://github.com/xiaodaozhi/xdstarter/issues/34)。

## 背景

当前布局仅保存 `dark`／`light`，界面依赖统一的深浅主题 token。增加跟随系统不能把第三个值悄悄写入旧格式，否则旧程序会把新文件当作损坏，而不是按未来版本只读保护。

## 决定

- 外观菜单提供跟随系统、浅色、深色三个明确选择；新用户和旧配置没有主题字段时仍采用原来的深色默认，原有显式浅色／深色选择不变。
- 新的 schemaVersion 5 在 `preferences.theme` 增加 `system`；版本 1–4 继续严格只接受原有值和字段。旧布局只在内存中迁移，正常保存时保留原文件字节为备份；旧程序对版本 5 进入未来版本只读保护。
- `system` 使用 Qt 6.8 的 `QStyleHints::colorScheme` 及变化信号；系统值未知时回退深色。系统变化仅更新有效颜色，不写偏好、不改变布局修订或导入预览；用户显式选择浅色／深色则不再跟随系统。
- 导入预览显示保存的偏好，确认后按当前系统状态计算外观；只读和导入提交中的用户更改仍被拒绝。48 DIP 小格、8 DIP 间隙及三档磁贴几何不随主题变化。
- 不调用 Qt 的主题覆盖 setter 改变进程或系统设置；测试可在独立进程内模拟提示变化。当前 Qt 6.8 不提供后续版本的高对比度偏好接口，高对比、减少动画及屏幕阅读器仍单独验收，不能由深浅主题回归推断通过。

## 验证边界

自动测试需覆盖旧版本严格校验与备份、system 保存／导入、手动覆盖、提示变化、未知回退和几何不变。进程内模拟不替代实际 Windows 主题切换；不修改本机系统设置进行常规测试。

依据：[Qt 6.8 QStyleHints](https://doc.qt.io/qt-6.8/qstylehints.html#colorScheme-prop)、[数据与持久化](../data-persistence.md)。
