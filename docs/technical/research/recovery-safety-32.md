# 睡眠与会话切换的恢复安全模型（#32）

此研究只在测试目标中构造门控模型，不修改产品的接管、系统通知注册或恢复行为。测试使用现有开始按钮和 Win 键纯状态机，输入、通知、时钟及注册结果均为夹具注入；Windows 夹具仅向本进程自有的消息窗口直接发送通知，没有注册系统电源／会话通知，也没有使系统睡眠或切换会话。

候选模型要求电源及会话通知源均已就绪、当前会话和桌面已确认、已拥有的鼠标按下及键盘状态已处理、时钟基线有效，才允许显式启用。收到本会话锁定／解锁、断开或电源事件后失效；重复事件不会自动恢复，属于旧代次的事件不影响新代次。已吞下的鼠标按下仍需配对处理释放，但不会触发打开；Win 键候选取消后释放继续传递。实际注册失败和系统事件的交付顺序尚未由此夹具验证。

时钟实验假设每次不含睡眠的时钟读数夹在两次含睡眠的时钟读数之间；根据两次读取的上下界计算经过时间与差值范围。倒退、读取失败或测量不确定时，模型拒绝继续接管；确认差值超出测试阈值时也拒绝继续。阈值仅为合成测试参数，不是经测量确定的产品阈值。差值落在阈值内不能证明没有短暂睡眠，时钟及其 Windows 实现、精度和通知丢失都需要另行验证。

测试还保留一个反例：如果恢复后的第一条输入先于任何通知或新时钟观测，夹具看到的状态与未睡眠时完全相同，仍可能接管该输入。异步通知加上定期采样本身不能排除这个窗口，因而不能据此宣称恢复已安全；在提出产品方案前，仍需设计并验证第一条输入的可靠判定、输入配对和无阻塞路径。真实睡眠、唤醒、锁屏及原生入口恢复应在经用户协调的 Windows 环境中验证，可使用合适的隔离环境，但不以可销毁虚拟机为唯一前提。
